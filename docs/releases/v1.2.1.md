Shotcue 1.2.1 fixes a crash when creating a project.

## Fixed

- **Creating a project no longer crashes.** Choosing **Oluştur** in the project editor quit the app while the sheet was closing. The project is now saved and selected, and the editor closes normally. Editing an existing project was affected in the same way and is fixed too.

## Upgrading from 1.1.0 or 1.2.0

The app offers this version on its own: choose **Güncelle** in the update window, or check by hand with *Güncellemeleri denetle…* in the menu bar.

Builds are ad-hoc signed, so macOS asks for Screen Recording and Microphone again after updating. If a switch in System Settings is already on but Shotcue still asks, remove Shotcue from that list (–) and grant it again.

## Install

- **Homebrew:** `brew install --cask egekibar/tap/shotcue`
- **DMG:** download `Shotcue-1.2.1.dmg` below, open it and drag **Shotcue** onto **Applications**. The build is not notarized: allow the first launch in System Settings → Privacy & Security → **Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Shotcue.app`.

Requirements: macOS 26 or later, Apple Silicon, and at least one coding agent CLI logged in: Claude Code (`claude`, with a Claude subscription), Codex (`codex`, logged in with ChatGPT) or Antigravity (`agy`).
