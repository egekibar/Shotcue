Shotcue 1.2.2 fixes library cards that kept showing a placeholder instead of their screenshot.

## Fixed

- **Card images show again.** In the library, cards could stay on their placeholder even though the screenshots were on disk, while Shotcue kept the CPU busy in the background. The thumbnail cache dropped images when the Mac was short on memory, so a card that asked for its image kept reloading it. Thumbnails now stay in memory until newer ones replace them (up to 256).

## Upgrading from 1.1.0 or later

The app offers this version on its own: choose **Güncelle** in the update window, or check by hand with *Güncellemeleri denetle…* in the menu bar.

Builds are ad-hoc signed, so macOS asks for Screen Recording and Microphone again after updating. If a switch in System Settings is already on but Shotcue still asks, remove Shotcue from that list (–) and grant it again.

## Install

- **Homebrew:** `brew install --cask egekibar/tap/shotcue`
- **DMG:** download `Shotcue-1.2.2.dmg` below, open it and drag **Shotcue** onto **Applications**. The build is not notarized: allow the first launch in System Settings → Privacy & Security → **Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Shotcue.app`.

Requirements: macOS 26 or later, Apple Silicon, and at least one coding agent CLI logged in: Claude Code (`claude`, with a Claude subscription), Codex (`codex`, logged in with ChatGPT) or Antigravity (`agy`).

## Türkçe özet

Shotcue 1.2.2, kütüphanedeki kartların ekran görüntüsü yerine yer tutucu göstermesini düzeltiyor. Görüntüler diskte olduğu halde kartlar boş kalabiliyor, Shotcue da arka planda işlemciyi meşgul ediyordu. Bunun nedeni, küçük resim önbelleğinin Mac'te bellek azaldığında resimleri kendiliğinden atması ve kartların resmi tekrar tekrar yüklemeye çalışmasıydı. Küçük resimler artık yenileri gelene kadar (en fazla 256) bellekte kalıyor. Güncelleme uygulamanın içinden gelir (**Güncelle**). Build ad-hoc imzalı olduğundan güncellemeden sonra Ekran Kaydı ve Mikrofon izinleri yeniden istenir.
