Shotcue 1.2.0 adds Codex and Antigravity as coding agents next to Claude Code.

## What's new

- **Codex and Antigravity.** Besides Claude Code, a task can now go to OpenAI's Codex CLI (`codex exec --json`, with the screenshots attached as images) or Google's Antigravity CLI (`agy -p --output-format stream-json`). Pick the default agent in Ayarlar → Ajanlar → *Varsayılan ajan*; a project can pick its own in *Proje ayarları* → *Ajan*. Both show a live log like Claude Code's, and *Terminalde devam et* continues the session with `codex resume <id>` or `agy --conversation <id>` (*Desktop'ta aç* stays Claude Code only). Each CLI runs with its own subscription login: Shotcue removes `OPENAI_API_KEY`, `CODEX_API_KEY`, `GEMINI_API_KEY` and `GOOGLE_API_KEY` from the run environment, as it already does with `ANTHROPIC_API_KEY`.
- **Ayarlar → Ajanlar.** The former Claude tab shows each CLI's version and path (found in the usual install locations, for `codex` also inside ChatGPT.app, or in your login shell's `PATH`; set *Yol* to override) with its own default model and effort. Codex offers `gpt-5.6-terra`, `gpt-5.6-luna` and `gpt-5.5`; Antigravity offers Gemini 3.1 Pro, Gemini 3.8 Flash, Claude Opus 4.6 and Claude Sonnet 4.6. The model pickers in the project editor and the inspector list the models of the task's own agent. The turn and budget limits apply to Claude Code only; the timeout and the concurrency limit apply to every agent.
- **Permissions per agent.** *Analiz* stays read-only: Codex runs in its read-only sandbox, Antigravity in plan mode. In *Uygula*, the default `bypassPermissions` runs Codex without approvals or sandbox (`--dangerously-bypass-approvals-and-sandbox`) and Antigravity without its terminal sandbox; `acceptEdits` or `dontAsk` keep Codex in the workspace-write sandbox (writes stay inside the project) and Antigravity in accept-edits mode with the terminal sandbox. Antigravity always skips its permission prompts, since nobody can answer them in a headless run. The project's git safety nets (new branch, stash) work the same for every agent.
- **Which agent ran it.** A run row shows the agent that ran it.

## Upgrading from 1.1.0

1.1.0 offers this version on its own: choose **Güncelle** in the update window, or check by hand with *Güncellemeleri denetle…* in the menu bar. Nothing changes until you pick another agent: the default agent is Claude Code, existing projects follow the default, and earlier runs are listed as Claude Code runs.

Builds are ad-hoc signed, so macOS asks for Screen Recording and Microphone again after updating. If a switch in System Settings is already on but Shotcue still asks, remove Shotcue from that list (–) and grant it again.

## Install

- **Homebrew:** `brew install --cask egekibar/tap/shotcue`
- **DMG:** download `Shotcue-1.2.0.dmg` below, open it and drag **Shotcue** onto **Applications**. The build is not notarized: allow the first launch in System Settings → Privacy & Security → **Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Shotcue.app`.

Requirements: macOS 26 or later, Apple Silicon, and at least one coding agent CLI logged in: Claude Code (`claude`, with a Claude subscription), Codex (`codex`, logged in with ChatGPT; tested with 0.148) or Antigravity (`agy`; tested with 1.2.9).

## Türkçe özet

Shotcue 1.2.0, Claude Code'un yanına Codex ve Antigravity'yi ekliyor: görevler artık OpenAI'nin Codex CLI'ına (`codex exec --json`, ekran görüntüleri görsel olarak eklenir) ya da Google'ın Antigravity CLI'ına (`agy -p`) da gönderilebilir. Varsayılan ajanı Ayarlar → Ajanlar'dan (eski Claude sekmesi) seç; bir proje kendi ajanını Proje ayarları'ndan seçebilir. Her CLI'ın sürümü, yolu, varsayılan modeli ve effort'u aynı sekmede. Loglar Claude Code'daki gibi canlı akar, *Terminalde devam et* oturumu `codex resume` / `agy --conversation` ile sürdürür. Tur ve bütçe limitlerini yalnızca Claude Code uygular; zaman aşımı ve eş zamanlılık her ajan için geçerli. Uygula modunda varsayılan `bypassPermissions` Codex'i sandbox'sız, Antigravity'yi terminal sandbox'ı olmadan çalıştırır; `acceptEdits` ya da `dontAsk` ikisini de sandbox'ta tutar. Çalıştırma satırı hangi ajanın çalıştırdığını gösterir. 1.1.0 bu sürümü uygulamanın içinden sunar; başka bir ajan seçmediğin sürece hiçbir şey değişmez (varsayılan ajan Claude Code). Build ad-hoc imzalı olduğundan güncellemeden sonra Ekran Kaydı ve Mikrofon izinleri yeniden istenir.
