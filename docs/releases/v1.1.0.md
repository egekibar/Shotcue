Shotcue 1.1.0 adds in-app updates and a Homebrew cask.

## What's new

- **In-app updates.** Shotcue checks GitHub Releases shortly after launch and then once a day. When a newer version is out, a window shows its release notes with **Güncelle** (update), **Sonra** (later) and **Bu sürümü atla** (skip this version). **Güncelle** downloads the DMG, verifies it against the release's `.sha256` file, checks the bundle id and version, then quits (running tasks are stopped after the usual confirmation), swaps the app in and reopens it. If the swap fails, the old app is restored. Check by hand from the menu bar (*Güncellemeleri denetle…*) or in Ayarlar → Genel → *Güncellemeler*, where automatic checks can be turned off.
- **Homebrew.** Install with `brew install --cask egekibar/tap/shotcue`. The cask clears the quarantine flag, so Shotcue opens without the Gatekeeper prompt. Because Shotcue updates itself, `brew upgrade` skips it unless you pass `--greedy`.
- **No more cost figure.** The estimated run cost is no longer shown in the notification, the run row or the log. With a Claude subscription it is only an API-price estimate and read like a bill; it is still recorded with the run.

## Upgrading from 1.0.0

1.0.0 has no updater, so install this version by hand once: download `Shotcue-1.1.0.dmg` below and drag **Shotcue** onto **Applications**, replacing the old app (or run `brew install --cask egekibar/tap/shotcue`). Later versions update from inside the app.

Builds are ad-hoc signed, so macOS asks for Screen Recording and Microphone again after installing. If a switch in System Settings is already on but Shotcue still asks, remove Shotcue from that list (–) and grant it again.

## Install

- **Homebrew:** `brew install --cask egekibar/tap/shotcue`
- **DMG:** download `Shotcue-1.1.0.dmg` below, open it and drag **Shotcue** onto **Applications**. The build is not notarized: allow the first launch in System Settings → Privacy & Security → **Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Shotcue.app`.

Requirements are unchanged: macOS 26 or later, Apple Silicon, and the Claude Code CLI logged in with a Claude subscription.

## Türkçe özet

Shotcue 1.1.0 uygulama içi güncelleme getiriyor: açılıştan kısa süre sonra ve günde bir kez GitHub Releases denetlenir; yeni sürüm varsa notlarıyla birlikte **Güncelle / Sonra / Bu sürümü atla** penceresi açılır, **Güncelle** DMG'yi indirip SHA-256 ile doğrular, uygulamayı değiştirip yeniden açar. Artık Homebrew ile de kurulabilir: `brew install --cask egekibar/tap/shotcue`. Tahmini çalıştırma maliyeti artık gösterilmiyor. 1.0.0'da güncelleyici olmadığı için bu sürümü bir kez elle (DMG ya da brew ile) kurman gerekiyor; sonraki sürümler uygulamanın içinden gelir. Build ad-hoc imzalı olduğundan kurulumdan sonra Ekran Kaydı ve Mikrofon izinleri yeniden istenir.
